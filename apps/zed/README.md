# Myrt Zed theme

Fine-tuned legacy GitHub theme for Zed. Contains many improvements for comfortable work with code for many hours. Best used with [Lilex font](https://github.com/mishamyrt/Lilex).

## Install

1. Download [latest release](https://github.com/mishamyrt/myrt-code-theme/releases/latetst)
2. Place `myrt-code.json` to:
  - macOS/Linux: `~/.config/zed/themes`
  - Windows: `%USERPROFILE%\AppData\Roaming\Zed\themes`
3. Select theme via Theme Selector.
